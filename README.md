# Pakistan-Economic-Outlook-Market-Analysis-Excel
Conducted a 2010–2025 analysis of Pakistan’s macroeconomic and financial-market trends using Microsoft Excel.
Analyzed GDP growth, inflation, monetary policy, USD/PKR exchange rates, exports, imports, remittances, current account, and KSE-100 performance. Built calculated indicators, correlation analysis, economic trend analysis, and market analysis to examine relationships between macroeconomic conditions and equity-market performance. Used data from sources including the World Bank, State Bank of Pakistan, and Pakistan Stock Exchange.
